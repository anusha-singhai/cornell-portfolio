# 📚 Book Review Sentiment Analyzer

A **Natural Language Processing (NLP)** project that uses a **Keras neural network** and **TF-IDF vectorization** to classify the sentiment of book reviews as positive or negative. This project demonstrates the use of machine learning for text analysis, from preprocessing raw text data to training and evaluating a deep learning model.

---

## Features

- **Neural Network Model** built using **Keras (TensorFlow backend)**
- **TF-IDF Vectorization** for text representation
- **Sentiment Classification** (Positive / Negative)
- **Model Evaluation** using accuracy, precision, recall, and F1 score
- Option to **save and load trained models**

---

## Tech Stack

- **Python**
- **TensorFlow / Keras**
- **scikit-learn**
- **NumPy**
- **pandas**
- **Matplotlib + Seaborn** (for visualization)
